# ☕ Barista School Poltava

Сучасний, високопродуктивний веб-застосунок (landing page) для школи бариста в Полтаві. Проект розроблено з акцентом на конверсію, швидкодію та бездоганний користувацький досвід (UX/UI). Інтегровано систему збору лідів через Telegram API.

## 🚀 Технологічний стек

- **Фреймворк:** [Next.js 16](https://nextjs.org/) (App Router)
- **Бібліотека UI:** React 19
- **Мова програмування:** TypeScript
- **Стилізація:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Анімації:** [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
- **Обробка форм:** `react-hook-form` + `zod`
- **Іконки:** `lucide-react`
- **Бекенд/Інтеграція:** Next.js Server Actions, Telegram Bot API

## ✨ Ключовий функціонал

- **Преміальний UI/UX дизайн:** Сучасна палітра кольорів, продумана типографіка та плавні мікроінтеракції. Використання фонового відео для посилення залученості користувачів.
- **Оптимізація конверсії:** Зручна та захищена форма зворотного зв'язку зі строгою валідацією на стороні клієнта та сервера за допомогою Zod.
- **Безпечна інтеграція з Telegram:** Дані з форм надсилаються безпосередньо в Telegram-групу за допомогою Server Actions, що гарантує прихованість API-ключів та загальну безпеку.
- **Technical SEO:** Налаштовані розширені мета-теги, OpenGraph, автоматична генерація `sitemap.xml` та `robots.txt` для ефективного просування в пошукових системах.
- **Адаптивність та швидкодія:** Повна підтримка всіх типів пристроїв (Responsive Web Design) з використанням сучасних CSS Grid та Flexbox лейаутів. Завантаження оптимізованих зображень через `next/image`.

## 🏗 Архітектурні рішення

- **Server-Side Processing:** Використання Next.js Server Actions дозволило уникнути створення окремих API-роутів для обробки форм, спростивши архітектуру та підвищивши рівень безпеки.
- **Type Safety:** Наскрізна типізація за допомогою TypeScript та Zod гарантує надійність даних від моменту вводу користувачем до відправки на сервер.
- **Легковагі анімації:** Замість важких бібліотек обрано AOS для забезпечення ефектів появи без втрати продуктивності та просідання FPS.

## 🛠 Розгортання та запуск локально

### Попередні вимоги

- Node.js 20.x або вище
- npm або yarn

### Встановлення

1. Клонуйте репозиторій та перейдіть до директорії проекту:

   ```bash
   git clone <repository-url>
   cd my-app
   ```

2. Встановіть залежності:

   ```bash
   npm install
   ```

3. Налаштуйте змінні середовища. Створіть файл `.env.local` у кореневій папці та додайте необхідні ключі для інтеграції з Telegram:

   ```env
   TELEGRAM_BOT_TOKEN=your_bot_token
   TELEGRAM_CHAT_ID=your_chat_id
   ```

4. Запустіть сервер для розробки:
   ```bash
   npm run dev
   ```

Відкрийте [http://localhost:3000](http://localhost:3000) у вашому браузері, щоб переглянути результат.
